# Security policy

## Supported versions

claude-plans has no release yet. Security fixes apply to the latest code on `master`. After the first release,
they apply to the latest version only.

## Report a vulnerability

Please do not report vulnerabilities in public issues, pull requests, or discussions.

Use the repository's [private report form](https://github.com/stimothy/claude-plans/security/advisories/new), which
only you and the maintainers can see. Include:

- what the problem is and what someone could do with it
- the steps to reproduce it
- the commit or version you tested, and your operating system

Remove secrets and personal data from anything you attach.

The maintainer will reply on the report. Please give them time to fix the problem before you describe it publicly.
